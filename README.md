# CS113 Garage Project Repository

---

This project demonstrates an online management panel for a garage shop, built using JavaFX. Its function and design are reported in a PDF.

## Navigation

- `project/assets` contains images and other media files used throughout the project.
- `project/database` contains the project's data, stored in `.csv` files for use with Java's `File` class.
- `project/core` contains the core Java classes and application logic.
- `project/gui` contains the JavaFX codebase responsible for the graphical interface.
- `project/CS113-Project-Report.pdf` reports and documents the project
