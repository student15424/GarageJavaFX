# CS113 Garage Project Repository

---

This project demonstrates an online management panel for a garage shop, built using JavaFX. Its function and design are reported in a PDF.

## Navigation

- `src/assets` contains images and other media files used throughout the project.
- `src/database` contains the project's data, stored in `.csv` files for use with Java's `File` class.
- `src/core` contains the core Java classes and application logic.
- `src/gui` contains the JavaFX codebase responsible for the graphical interface.
- `src/CS113-Project-Report.pdf` reports and documents the project

## Setup & Usage

1. **Clone in GitHub Desktop:**
   - Open **GitHub Desktop** → **File → Clone Repository...** → select `student15424/GarageJavaFX`.
2. **Open in NetBeans:**
   - Open **Apache NetBeans** → **File → Open Project...** → select the cloned folder.
   - Press **Run Project (`F6`)** to build and launch the JavaFX window.
3. **Syncing Changes:**
   - Click **Fetch origin / Pull origin** in GitHub Desktop before starting work.
   - After saving your code in NetBeans, write a summary in **GitHub Desktop**, click **Commit to main**, and click **Push origin**.
