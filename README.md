# CS113 Garage Project Repository | مستودع مشروع ورشة الصيانة (CS113)

---

This project demonstrates an online management panel for a garage shop, built using JavaFX. Its function and design are reported in a PDF.

يستعرض هذا المشروع لوحة إدارة لورشة صيانة مبنية باستخدام **JavaFX**، مع توثيق وظائف المشروع وتصميمه في ملف PDF.

---

## Navigation | هيكل المشروع

- `src/assets` — contains images and other media files used throughout the project.  
  يحتوي على الصور وملفات الوسائط المستخدمة في المشروع.
- `src/database` — contains the project's data, stored in `.csv` files for use with Java's `File` class.  
  يحتوي على بيانات المشروع المخزنة بصيغة `.csv` للتعامل معها عبر كلاس `File` في جافا.
- `src/core` — contains the core Java classes and application logic.  
  يحتوي على الكلاسات الأساسية ومنطق البرنامج.
- `src/gui` — contains the JavaFX codebase responsible for the graphical interface.  
  يحتوي على أكواد واجهة المستخدم الرسومية (JavaFX).
- `src/CS113-Project-Report.pdf` — reports and documents the project.  
  ملف التقرير والتوثيق الخاص بالمشروع.

## Setup & Usage | طريقة التشغيل والاستخدام

1. **Clone in GitHub Desktop | نسخ المستودع عبر GitHub Desktop:**
   - Open **GitHub Desktop** → **File → Clone Repository...** → select `student15424/GarageJavaFX`.
   - افتح برنامج **GitHub Desktop** ثم اختر **File → Clone Repository...** وحدد المستودع `student15424/GarageJavaFX`.

2. **Open in NetBeans | فتح المشروع في NetBeans:**
   - Open **Apache NetBeans** → **File → Open Project...** → select the cloned folder.
   - افتح **Apache NetBeans** ثم اختر **File → Open Project...** وحدد مجلد المشروع الذي تم نسخه.
   - Press **Run Project (`F6`)** to build and launch the JavaFX window.
   - اضغط على **Run Project (`F6`)** لتشغيل المشروع وفتح نافذة JavaFX.

3. **Syncing Changes | مزامنة التعديلات ورفعها:**
   - Click **Fetch origin / Pull origin** in GitHub Desktop before starting work.
   - قبل البدء بالعمل، اضغط على **Fetch origin / Pull origin** في GitHub Desktop لسحب آخر التحديثات.
   - After saving your code in NetBeans, write a summary in **GitHub Desktop**, click **Commit to main**, and click **Push origin**.
   - بعد حفظ التعديلات في NetBeans، اكتب وصفاً مختصراً للتعديل في **GitHub Desktop** ثم اضغط **Commit to main** ثم **Push origin**.
