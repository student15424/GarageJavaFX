# Garage Management Project | مشروع ادارة كراج

---

This project demonstrates an online management panel for a garage shop, built using JavaFX. Its function and design are reported in a PDF.

يستعرض هذا المشروع لوحة لأدارة كراج رقمي باستخدام **JavaFX**، وظائف المشروع وتصميمه موثقة في ملف PDF.

---

## Project Structure | هيكل المشروع

- `src/assets` — contains images and other media files used throughout the project.  
  يحتوي على الصور والوسائط المستخدمة.

- `src/database` — contains the project's data, stored in `.csv` files for use with Java's `File` class.  
  يحتوي على بيانات المشروع بصيغة `.csv` للتعامل معها من كلاس `File`

- `src/core` — contains the core logical Java classes.
  يحتوي على الكلاسات الأساسية.

- `src/gui` — contains the JavaFX codebase for GUI.  
  يحتوي على أكواد واجهة المستخدم (JavaFX).

- `src/CS113-Project-Report.pdf` — reports and documents the project.  
  ملف لتقرير وتوثيق المشروع.
